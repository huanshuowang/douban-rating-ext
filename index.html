原理

放心查，就像你亲手点开一样。

豆瓣的搜索接口对海外 IP 限流很严（常见「搜索访问太频繁」），所以插件从头到尾不碰豆瓣搜索。

你点了图标

在这之前插件什么都不做。浏览网页期间零请求。

问搜索引擎

用片名去 Google / Bing / 百度 搜，从结果摘要里读豆瓣评分和条目链接。

最多读一个条目页

拿到条目后读那一页核对官方分数，结果缓存 7 天。

对豆瓣来说，这和你手动点开一次条目页没有区别。插件没有自己的服务器，不收集、不上传你的浏览记录。隐私政策 →

安装

30 秒装好。

已上架 Chrome 应用商店。Edge、Arc、Brave 等 Chromium 内核浏览器同样可以从商店安装。

前往 Chrome 应用商店
  1. 打开商店页点左边的按钮，进入「这豆瓣评分多少？」的商店页面。
  2. 添加至 Chrome点右上角「添加至 Chrome」，在弹窗里确认「添加扩展程序」。
  3. 固定到工具栏推荐点工具栏的拼图图标，把插件钉住，随时一点即查。也可以按 ⌃⇧D（Windows 上是 Alt+Shift+D），或选中片名后右键「查豆瓣评分」。

问答

常见问题

为什么有时会提示「可能不是《…》」？

搜到的豆瓣条目和你的片名对不上时（比如「逃出绝命镇」和「逃出绝命街」），或者标题里写着 2026 年、条目却是多年前的同名片，插件会按豆瓣官方的「中文名 · 原名」显示结果，同时提醒你。改一下搜索框或点「也可能是」里的候选即可。

为什么有时要「打开豆瓣验证」？

豆瓣偶尔会对访问做人机验证。在浏览器里打开一次条目页就会自动通过，之后一段时间插件都能直接读分；换网络（比如切换 VPN）或隔得久了，豆瓣可能会再要求一次。验证期间如果搜索结果里有对得上的分数，插件也会直接显示。

识别出来的片名不对怎么办？

弹窗打开时片名已经被选中，直接输入新的片名回车就行。也可以点下方的百度 / 豆瓣 / Google / Bing 手动搜索。

在国内能用吗？

能。三家搜索引擎同时查询，Google 访问不了时会自动用 Bing 或百度的结果。

会读取或上传我的浏览记录吗？

不会。插件只在你点图标（或按快捷键、右键查分）的那一刻读取当前页面的标题、简介和标签，或你选中的文字，用来判断片名；片名直接从你的浏览器发给搜索引擎。没有开发者服务器，详见隐私政策。

哪些页面认得最准？

流媒体详情页、搜索结果页、B 站正片和解说视频、YouTube 预告片最准。番剧分季、冷门译名、竖屏短视频偶尔需要手动改一下片名。
